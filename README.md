# Event Discovery Web Page

A responsive, interactive events discovery page built for the Dynamics 360 Web Development Internship Case Study.

## Live Demo

[View the live demo here](https://amilokz.github.io/events-discovery/) 


## Features

✅ **Responsive Design** - Works on mobile, tablet, and desktop  
✅ **Search Functionality** - Filter events by name, location, or description  
✅ **Event Cards** - Display event details with register buttons  
✅ **Interactive UI** - Hover effects, transitions, and responsive navigation  
✅ **Mobile Menu** - Hamburger menu for small screens  
✅ **Loading States** - Shows loading indicator while fetching data  
✅ **No Results Message** - Helpful message when no events match search  
✅ **Register Functionality** - Interactive register buttons with feedback  

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with CSS Grid and Flexbox
- **JavaScript (ES6+)** - Vanilla JS for interactivity
- **Font Awesome** - Icons
- **Google Fonts** - Typography

## How to Run Locally

1. **Clone or download** the project files to your computer
2. **Open `index.html`** in your web browser
3. **That's it!** No build process or dependencies required

Alternatively, you can use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have it installed)
npx serve .

# Using PHP
php -S localhost:8000

Then visit http://localhost:8000 in your browser.

How to Use

Register for events - Click "Register Now" on any event card
